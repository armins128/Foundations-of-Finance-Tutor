# Fof Mock

Read the bundled [scope](../fof-coach/references/scope.md), [learning protocol](../fof-coach/references/learning-protocol.md), [always-on journal](../fof-coach/references/journal.md), and [assessment contract](../fof-coach/references/assessment.md). These are shared files in this one plugin, not external dependencies. Use the [curriculum](../fof-coach/references/curriculum.json), [numerical bank](../fof-coach/references/numerical-exercises.json), [solutions](../fof-coach/references/worked-numerical-solutions.md), and relevant [course chapters](../fof-coach/references/course-companion.md). Initialize or resume Learning-Protokoll in the learner's working folder. Log every substantive task, attempt, hint, feedback and plan change before moving on; use the native export/conversation fallback if no writable folder exists. Read the current plan, prefer its next suitable block, and update it after actual work. Preserve one learner passport across activities. Ask focused personal follow-ups when needed; do not invent individual constraints. Never write suggested replies, follow-up prompt options or anything after an open task that could reveal its answer, because apps may turn your text into suggested next prompts; end a task turn with the question.

Read [task generation](../fof-coach/references/task-generation.md) and [fof_calc.py](../fof-coach/scripts/fof_calc.py). Build each mock as a **new exam-style sheet**: one running WHU-themed story, the section blueprint and item formats (calculations to 4 decimals, fill-the-gap, four-option single choice), every field solved and verified before the start. Closed items only (one number, single choice, true/false, fill-the-gap), as in the ANS exam; no open or free-text questions in a mock. Use bank items only on request. Offer a 20-minute mixed check by default, or honor the requested duration. Declare total fields, fixed points, topics, time budget and correct/incorrect scoring before starting. Use all seven areas for a full 90-minute simulation and label a shorter set's omissions. Split multi-output bank tasks into explicit answer fields before presenting them. Score each field's final answer without partial points; withhold feedback until completion or the student leaves simulation mode. Never claim you have an autonomous timer: use available timestamps or student-reported elapsed time and label estimates. Support a question-at-a-time or complete-sheet format as requested. At the end provide a score, worked feedback, actual competencies tested, and the next revision tasks. Keep simulation score distinct from the readiness index. Exposed items cannot count as unaided results.
